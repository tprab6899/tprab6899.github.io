# PainMap prototype (for testers)

This repository hosts the PainMap tester prototype as a website on GitHub Pages.
Testers open the link and go straight into the app, with no account or sign-in.

- Premium is unlocked for testers. Add `?startPremium=false` to the link to see the free version.
- It works on phones and computers. The 3D body is about 10 MB, so the first load takes a few seconds.
- PainMap gives general information, not medical advice.
